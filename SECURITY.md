# Security policy

spheropack is a numerical library without network access or privileged operations.
If you nevertheless find a security problem (for example a crash that can be triggered
by crafted input in a service that uses spheropack), please report it privately via
[GitHub security advisories](https://github.com/computational-chemical-engineering/spheropack/security/advisories/new)
rather than in a public issue. Only the latest release is supported.
