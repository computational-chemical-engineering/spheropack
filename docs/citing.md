# Citing

If you use spheropack in published work, please cite the version you used; citation
metadata is in
[CITATION.cff](https://github.com/computational-chemical-engineering/spheropack/blob/main/CITATION.cff)
(GitHub shows a "Cite this repository" button).

The algorithm is the Lubachevsky-Stillinger algorithm {cite:p}`lubachevsky1990`; the
collision rule in the growing frame and the use of event-driven molecular dynamics for
jamming follow {cite:t}`donev2005a` and {cite:t}`skoge2006`. For the rejection-free
Monte Carlo method (from version 0.2) please cite {cite:t}`peters2012`.
